# Code of Conduct

GPT Newspaper follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, be constructive, assume good intent, and make this a welcoming project for people of
every background and experience level. Harassment of any kind is not tolerated.

Report unacceptable behavior to rotem5707@gmail.com. All reports are reviewed promptly and kept confidential.
